Static single-page application served as plain HTML/CSS/JS with one server-side endpoint. `index.html` is the sole page: it embeds all CSS in a `<style>` block and all JS in an IIFE at the bottom, using no build step or framework. Content is duplicated per language via paired `<span class="ru">` / `<span class="en">` nodes toggled by setting `data-lang` on `<body>`. Sections are semantic `<section>` elements (`#home`, `#services`, `#formula`, `#stages`, `#works`, `#contacts`) driven by vanilla JS `IntersectionObserver` for scroll-triggered reveals, active nav highlighting, a stages progress rail, animated counters, and a cursor-following service preview image. The only backend is `send-brief.php`, a standalone PHP script that validates POST input, builds a plain-text email via `mail()`, and returns JSON responses; it is called from the embedded form via its `action` attribute. Deployment is governed by `.htaccess` (HTTPS redirect, security headers, 1-year cache for static assets, gzip compression) and `robots.txt` / `sitemap.xml` for SEO. Assets live under `images/` (hero photo and stand photos).
