The entire site is a flat, zero-dependency deployment rooted at the repository root. `index.html` is the sole page: it embeds all CSS in an inline `<style>` block and all JS in an IIFE at the bottom of the document, so no build step or asset pipeline exists. Content is duplicated per language via paired `<span class="ru">` / `<span class="en">` siblings toggled by setting `data-lang` on `<body>`. The page is divided into semantic `<section>` elements (`#home`, `#services`, `#formula`, `#stages`, `#works`, `#contacts`) whose scroll-driven animations are driven by vanilla `IntersectionObserver` instances scoped to element groups (`.rv`, `.lm-wrap`, `.count`, stage articles). The only server-side logic lives in `send-brief.php`, a standalone PHP script that validates POST input, builds a plain-text email via `mail()`, and returns JSON responses; it is invoked directly from the embedded form's `action` attribute. Deployment and runtime behavior are governed by `.htaccess` (HTTPS redirect proxy-safe via `X-Forwarded-Proto`, security headers, 1-year cache for static assets, gzip compression) alongside `robots.txt` and `sitemap.xml` for SEO. All visual assets live under `images/` (hero photo and stand photos). There are no sub-packages, frameworks, or external dependencies beyond Google Fonts.
