Single-page static site composed of one HTML document (`index.html`) containing all CSS and inline JavaScript, plus a single PHP endpoint (`send-brief.php`) that receives POST submissions via XMLHttpRequest. The HTML is structured as sequential `<section>` blocks (hero → services → formula → stages → works → stats → contacts → footer), each styled with scoped CSS variables in `:root` and animated via IntersectionObserver-driven reveal classes (`rv`, `lm-wrap`). Bilingual content is implemented by pairing `<span class="ru">` / `<span class="en">` nodes toggled through `document.body.setAttribute('data-lang', 'ru'|'en')`. The form at `#contacts` posts to `send-brief.php` using `FormData`; the PHP script validates input, strips tags, enforces allowed values for the area field, builds a plain-text email body, and sends it via PHP's `mail()` with `-f emoo@emoo.ru`. Static assets are co-located images (`hero.jpg`, `stand-*.jpg`) referenced directly from the markup. There is no build step or framework — deployment is a flat file copy onto any PHP 7.4+ host with `mail()` enabled.
